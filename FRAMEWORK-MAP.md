# Framework Map

References are separated from claims. A URL or copied control catalog is not evidence of implementation.

| Source | Intended use | Claim status |
| --- | --- | --- |
| NIST CSF 2.0 | Enterprise cybersecurity outcomes | Referenced; mapping required |
| NIST SP 800-207 | Zero Trust architecture principles | Referenced; implementation evidence required |
| NIST AI RMF | AI risk governance and lifecycle | Planned mapping |
| CSA CCM | Cloud control taxonomy and shared responsibility | Source data present; organizational applicability must be approved |
| ISO/IEC 27001 | ISMS requirements | No certification claim |
| ISO/IEC 42001 | AI management system requirements | No certification claim |
| Apple PKI CP/CPS | Apple certificate trust and practice context | External dependency reference only |

Every implemented control receives a stable internal ID, owner, scope, source mapping, implementation statement, evidence pointer, test frequency, exceptions, and review date.
