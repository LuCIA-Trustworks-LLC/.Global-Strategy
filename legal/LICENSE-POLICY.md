# License Policy

One license must not be applied indiscriminately to code, documentation, models, datasets, media, generated output, trademarks, and third-party material.

## Required classification

| Asset class | License treatment |
| --- | --- |
| Original source code | Project-specific code license; **not selected by this baseline** |
| Documentation/policy text | CC BY-NC-SA 4.0 only when explicitly marked |
| Swift toolchain/source | Upstream Apache License 2.0 with Runtime Library Exception |
| Apple SDKs/Xcode/services | Apple agreements and applicable terms; not relicensed by this repository |
| Third-party packages/actions | Retain upstream license, notices, version, source, and review status |
| AI model/API | Provider terms, acceptable-use limits, data-use terms, and model-specific license |
| Model weights | Weight-specific license; never infer from code license |
| Dataset | Dataset-specific rights, provenance, consent, purpose, and retention terms |
| AI-generated asset | Record generator, prompts/input rights, human review, restrictions, and destination license decision |
| Brand/trademark | Separate trademark permission; copyright license does not grant trademark rights |

## Release gate

No asset is released until its owner, origin, license identifier or governing terms, compatibility, attribution, modification status, and distribution conditions are recorded in `THIRD_PARTY.yml` or an equivalent approved register. Unknown means blocked, not permissive.

This policy is operational guidance, not legal advice. Novel, ambiguous, or commercially significant cases require qualified legal review.
